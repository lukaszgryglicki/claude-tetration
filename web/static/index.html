Function
Arguments

Each argument is a number or a constant expression: 2, -0.5, 1.5+0.5i, pi, e^(1/e), sqrt(2), 2^^0.5, ate(2, 16). Of four numbers each must be real. Syntax, constants and functions.

API:

API: /?prec=20&func=tet&base=2&height=0.5, /?func=ate&base=2&value=65536, /?func=ssrt&value=16&height=3, or with four real numbers /?func=tet&base_re=1.5&base_im=0.5&height_re=1&height_im=0.7. The reply is JSON; &format=text gives the two lines that tet prints. In a URL a + is a plus sign and a space is %20.

Results are computed by tet on this server, within a time limit (see stats), and kept in memory until the server restarts. Source: claude-tetration (AGPL-3.0).
