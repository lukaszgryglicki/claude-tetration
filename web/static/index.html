tet complex tetration to any precision

Function
Arguments
{{arguments}}

Each argument is a number or a constant expression: 2, -0.5, 1.5+0.5i, pi, e^(1/e), sqrt(2), 2^^0.5, ate(2, 16). Of four numbers each must be real. Syntax, constants and functions.

{{result}}

Documentation: this page and its API; tet itself: the mathematics, the methods, their limits and the credits; the syntax of the arguments.

References: Tetration online calculator, the thread about this page on the Tetration Forum, whose members' work tet implements; tet-line and rust-opengl-complex-drawer, two viewers that plot expressions with tetration, along a line and over a rectangle of the complex plane: tet computes every tetration in them.

API: /?prec=20&func=tet&base=2&height=0.5, /?func=ate&base=2&value=65536, /?func=ssrt&value=16&height=3, or with four real numbers /?func=tet&base_re=1.5&base_im=0.5&height_re=1&height_im=0.7. The reply is JSON; &format=text gives the two lines that tet prints. In such a URL a + is a plus sign and a space is %20.

Results are computed by tet on this server, to as many digits as are asked for, and kept in memory until the server restarts. A calculation that is not ready after {{wait}} continues there, for up to {{limit}}: this page then asks again by itself, and the same request made later, here or to the API, finds the calculation running, or its result. At most {{jobs}} calculations run at a time: while all of them are busy a new one is turned away, to be asked for again later. Source: claude-tetration (AGPL-3.0){{revision}}.

symbolic-math computer algebra to any precision

Results
Numbers

An input is what follows symbolic-math on its command line: x^2 - 5x + 6 = 0, integrate(x^2*e^(-x), x, 0, inf), a := 3; a^2. The inputs of a run share their definitions; a line that begins with # is a remark. save_png("name.png", drawing, width = 900) and save_jxl("name.jxl", drawing) make pictures to look at and to download. Where scripts run, Ctrl+Enter in the field calculates. Every kind of operation with examples.

Examples (a click runs one): {{sm.examples}}

{{sm.all}}
{{sm.result}}

Documentation: the full help of symbolic-math --help, an example of every kind of operation; the lists of its functions, constants and units; the repository on GitHub with its README.

What it does: simplifies, solves equations, systems and inequalities, differentiates, integrates, takes limits, sums and series, works with matrices, polynomials, statistics, special functions, transforms, numbers in any base, units, tetration (through tet) and fractional iterates of functions; it draws charts as text and as PNG and JPEG XL pictures.

API: /sm?expr=x^2-5x%2B6=0, /sm?expr=N(pi)&digits=100&mode=numeric, with mode (both, numeric, exact) and domain (complex, real, quaternion). Several inputs are lines of expr, with %0A between them. The reply is JSON with the output and the files of the run; &format=text gives the output as the program prints it. In such a URL a + is a plus sign (%2B is one as well) and a space is %20.

Every run is a symbolic-math process on this server, in a directory of its own that is removed afterwards; results are kept in memory until the server restarts, with the same limits and the same slots as the calculations of tet. Source: symbolic-math (AGPL-3.0).
